# TOOLS.md - 本地备注

Skills 定义工具*如何*工作。这个文件用于记录*你的*具体情况，也就是你的环境所独有的信息。

## 应该记录什么

例如：

- 摄像头名称和位置
- SSH 主机和别名
- TTS 的首选语音
- 音箱或房间名称
- 设备昵称
- 任何与环境有关的特殊信息

## 示例

```markdown
### 摄像头

- living-room → 主要活动区域，180° 广角
- front-door → 入口，移动触发

### SSH

- home-server → 192.168.1.100，用户：admin

### TTS

- 首选语音：“Nova”（温暖，略带英式口音）
- 默认音箱：厨房 HomePod
```

## 为什么要分开记录

Skills 是共享的，而你的环境配置属于你自己。将两者分开，意味着你可以更新 Skills 而不丢失自己的备注，也可以分享 Skills 而不泄露自己的基础设施信息。
