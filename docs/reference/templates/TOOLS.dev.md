# TOOLS.md - 用户工具备注（可编辑）

这个文件用于记录*你的*外部工具和使用惯例。
它不负责定义有哪些工具；OpenClaw 会在内部提供内置工具。

## 示例

### imsg

- 发送 iMessage/SMS：说明要发给谁、发送什么，并在发送前确认。
- 优先使用短消息；不要发送秘密。

### sag

- 文本转语音：指定语音、目标音箱或房间，以及是否采用流式播放。

添加任何你希望助手了解的本地工具链信息。
